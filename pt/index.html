Perguntas frequentes

Tudo claro antes de começar.

Como meu clube começa com o PGO?

Solicite uma demonstração para conhecer a plataforma. Para receber reservas, o clube deve estar aprovado, com quadras ativas, horários, durações e preços configurados.

Como os jogadores reservam?

O jogador acessa o PGO, escolhe clube, data e duração e seleciona um horário disponível na grade para continuar a reserva.

Como são realizados os pagamentos?

O jogador segue as instruções e os meios de pagamento disponibilizados pelo clube. Esta landing page não processa pagamentos bancários.
